# Memory

## Project Overview

pnpm + Turborepo monorepo. TanStack Start + Router (React 19, SSR), Tailwind v4, shadcn/ui. TypeScript 6, Vite 8.

- **Package Manager:** pnpm@10.33.4 (enforced via `packageManager` field)
- **Node Version:** >=20 (required)
- **shadcn/ui Style:** radix-nova (Phosphor icons)

## Commands

- `pnpm dev` — both apps. `pnpm dev:admin` (port 3000) / `pnpm dev:user` (port 3001)
- `pnpm build` / `pnpm lint` / `pnpm typecheck` / `pnpm format` — turbo pipelines, run on all workspaces
- `pnpm start` in `apps/paperless-admin` — custom Express SSR dev via `tsx server.ts`
- No test framework exists; verification = `pnpm lint && pnpm typecheck`

## Architecture

- `apps/paperless-admin/` — custom Express SSR (`server.ts` root dir). Vite middleware in dev, serves `dist/server/server.js` in prod. SSO auth via `createServerFn`, sets `__Host-session` HttpOnly cookie. Uses `@/*` path alias.
- `apps/paperless-user/` — simpler TanStack Start app, no custom server logic
- `packages/ui/` — shadcn/ui (`radix-nova` style, Phosphor icons), TipTap editor, globals.css. CSS imported as `@workspace/ui/globals.css?url`
- `packages/api-client/` — Axios wrapper. Reads `token` from `js-cookie` on client, redirects on 401/403/503
- `packages/types/` — shared TS types (currently empty index.ts, populated on demand)
- `packages/utils/` — `formatCurrency`, `formatDate`, etc.
- `packages/forms/` — shared form components and TanStack Form integrations

## Framework Quirks

- `routeTree.gen.ts` is auto-generated by TanStack Router — never edit manually
- `verbatimModuleSyntax` enabled — use `import type` for type-only imports
- Prettier: no semicolons, double quotes, `prettier-plugin-tailwindcss` for class sorting
- ESLint uses `@tanstack/eslint-config` (per-package, no root config). Disabled rules: `import/no-cycle`, `import/order`, `sort-imports`, `@typescript-eslint/array-type`, `@typescript-eslint/require-await`, `pnpm/json-enforce-catalog`. Unused vars pattern: `^_` (prefix with underscore to ignore).
- `.env*` gitignored; admin needs `VITE_BASE_URL` + `VITE_PORTAL_URL` (see `apps/paperless-admin/.env`)
- Build artifacts: `.output/`, `.tanstack/`, `dist/`, `dist-ssr/`, `apps/*/src/**/*.js`, `packages/*/src/**/*.js`, `graphify-out/`

## Graphify Workflow

Graphify generates code knowledge graphs per-app (not at root) for focused context and faster queries.

### Generate/Regenerate Graphs

After structural changes (new features, major refactors, new components):

```bash
graphify apps/paperless-admin --code-only
graphify cluster-only apps/paperless-admin

graphify apps/paperless-user --code-only
graphify cluster-only apps/paperless-user
```

### Graph Outputs

- `apps/paperless-admin/graphify-out/` — 564 nodes, 62 communities
- `apps/paperless-user/graphify-out/` — 498 nodes, 27 communities
- Each contains: `graph.json`, `graph.html`, `GRAPH_REPORT.md`, `.graphify_analysis.json`

### Query Usage

Use graphify query tools within each app's context:
- `graphify query "search term" apps/paperless-admin/graphify-out`
- `graphify explain "symbol" apps/paperless-admin/graphify-out`
- `graphify path "from" "to" apps/paperless-admin/graphify-out`

### Best Practices

- Regenerate graphify after: new file structures, major component refactors, dependency changes
- Keep `graphify-out/` gitignored (auto-regenerated, not source)
- Use app-specific graphs to avoid noise from cross-app code
